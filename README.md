# Pokémon Battle Simulator

This Pokémon battle simulation application allows users to create teams of Pokémon and simulate battles between them. The application is built using React for the frontend and utilizes Supabase as the backend for data storage and management.

## Prerequisites

Before you begin, ensure you have met the following requirements:
- Node.js (version 12.x or higher)
- npm (or yarn, if preferred)
- Access to a Supabase project

## Installation

1. **Clone the repository:**
   ```bash
   git clone git@github.com:Oussama-Fajraoui/Pokemon_Challenge_REACT.git
   cd Pokemon_Challenge_REACT

2. **Install dependencies::**

  npm install

3. **Set envirmont variable::**

  Set up environment variables:
  VITE_SUPABASE_URL
  VITE_SUPABASE_KEY

4. **Run application::**


  npm run dev
